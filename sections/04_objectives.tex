\section{Objetivos}

\begin{frame}{Objetivo Geral}
  \begin{block}{}
    Criação de um \textit{framework} completo que seja capaz de estruturar conjuntos de
    dados conversacionais novos e já existentes afim de adequá-los à tarefa de
    treinamento de \textit{TTS} conversacionais \textit{SOTA} específicos e, em seguida,
    avaliar o desempenho desses novos conjuntos de dados sob a ótica de métricas
    dedicadas ao contexto conversacional.
  \end{block}
\end{frame}

\begin{frame}{Objetivos Específicos}
  \begin{block}{}
    \begin{enumerate}
      \item[1] Adaptar o conjunto de dados MuPe\cite{evaldo-leal-etal-2025-mupe} à tarefa
        de \textit{TTS} conversacional e avalia-lo no modelo proposto.
      \item[2] Criação de um pipeline para adequar um conjunto de dados de fala editada
        (dados do \textit{PECEGE}) à tarefa de treinamento de modelos de \textit{TTS}
        conversacionais.
    \end{enumerate}
  \end{block}
\end{frame}
